# Ensure That Cloud SQL Database Instances Do Not Implicitly Whitelist All Public IP Addresses

| Provider | Category | CIS Control (GCP v5.0.0) |
| -------- | -------- | ------------------------ |
| Google Cloud Platform | Network security | 6.5 |

## Description

This control checks that no `settings.ip_configuration.authorized_networks` entry of a `google_sql_database_instance` allows any address. The same check applies to `cloudsql.settings.ip_config.authorized_networks` in `google_database_migration_service_connection_profile` resources that create Cloud SQL destinations; source-only profiles are outside this check. Any value with a `/0` prefix length, such as `0.0.0.0/0` or `::/0`, fails. Omitted or empty authorized-network lists pass. Ranges that split the address space into several entries (for example `0.0.0.0/1` and `128.0.0.0/1`) are not detected.

An authorized network of `0.0.0.0/0` lets any host on the internet reach the instance's public IP address, leaving only database authentication between attackers and the data. Restricting authorized networks to known addresses reduces the attack surface.

This rule is covered by the [cloudsql-no-open-authorized-networks](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/cloudsql-no-open-authorized-networks.policy.hcl) policy.
