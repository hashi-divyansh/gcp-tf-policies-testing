# Ensure '3625 (trace flag)' Database Flag for all Cloud SQL SQL Server Instances Is Set to 'on'

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Database security |

## Description

This control checks that Cloud SQL for SQL Server instances (`google_sql_database_instance` with a `SQLSERVER` `database_version`) set the `3625` trace flag to `on`. Values are compared case-insensitively. If the flag is not set, the instance fails because the engine default is non-compliant. Read replicas are evaluated too, because database flags are not inherited from the primary.

Trace flag 3625 masks the parameters of some error messages for users who are not members of the sysadmin role. This limits the information that error messages disclose to non-privileged users.

This rule is covered by the [6-3-6-trace-flag-3625](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/6-3-6-trace-flag-3625.policy.hcl) policy.
