# Ensure 'contained database authentication' Database Flag for Cloud SQL SQL Server Instance Is Set to 'off'

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Database security |

## Description

This control checks that Cloud SQL for SQL Server instances (`google_sql_database_instance` with a `SQLSERVER` `database_version`) set the `contained database authentication` database flag to `off`, if it is set. Values are compared case-insensitively. If the flag is not set, the instance passes because the engine default is compliant. Read replicas are evaluated too, because database flags are not inherited from the primary.

Contained databases authenticate users inside the database instead of at the server level. Users of a contained database can bypass server-level login policies, and database owners can create users without server administrators being aware of them.

This rule is covered by the [6-3-7-contained-db-auth-off](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/6-3-7-contained-db-auth-off.policy.hcl) policy.
