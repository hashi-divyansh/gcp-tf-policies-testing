# Ensure That the 'Local_infile' Database Flag for a Cloud SQL MySQL Instance Is Set to 'Off'

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Database security |

## Description

This control checks that Cloud SQL for MySQL instances (`google_sql_database_instance` with a `MYSQL` `database_version`) set the `local_infile` database flag to `off`. Values are compared case-insensitively. If the flag is not set, the instance fails because the engine default is non-compliant. Read replicas are evaluated too, because database flags are not inherited from the primary. The same check applies to `google_database_migration_service_connection_profile` resources that create a Cloud SQL destination instance through `cloudsql.settings.database_flags`.

`local_infile` allows clients to load files from their local file system into the database with `LOAD DATA LOCAL`. Disabling it removes a path for reading files and exfiltrating or injecting data through compromised clients or SQL injection.

This rule is covered by the [6-1-3-local-infile-off](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/6-1-3-local-infile-off.policy.hcl) policy.
