# Ensure 'remote access' Database Flag for Cloud SQL SQL Server Instance Is Set to 'off'

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Database security |

## Description

This control checks that Cloud SQL for SQL Server instances (`google_sql_database_instance` with a `SQLSERVER` `database_version`) set the `remote access` database flag to `off`. Values are compared case-insensitively. If the flag is not set, the instance fails because the engine default is non-compliant. Read replicas are evaluated too, because database flags are not inherited from the primary.

`remote access` allows stored procedures to be run from or on remote SQL Server instances. Disabling it prevents the instance from being used to run code on other servers, or being controlled by them.

This rule is covered by the [6-3-5-remote-access-off](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/6-3-5-remote-access-off.policy.hcl) policy.
