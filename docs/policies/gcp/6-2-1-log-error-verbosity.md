# Ensure 'Log_error_verbosity' Database Flag for Cloud SQL PostgreSQL Instance Is Set to 'DEFAULT' or Stricter

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Logging |

## Description

This control checks that Cloud SQL for PostgreSQL instances (`google_sql_database_instance` with a `POSTGRES` `database_version`) set the `log_error_verbosity` database flag to `default` or `terse`, if it is set. Values are compared case-insensitively. If the flag is not set, the instance passes because the engine default is compliant. Read replicas are evaluated too, because database flags are not inherited from the primary. The same check applies to `google_database_migration_service_connection_profile` resources that create a Cloud SQL destination instance through `cloudsql.settings.database_flags`.

`log_error_verbosity` controls how much detail PostgreSQL writes for each logged message. `verbose` adds source-code locations and internal details that increase log volume and can expose implementation information without improving security monitoring.

This rule is covered by the [6-2-1-log-error-verbosity](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/6-2-1-log-error-verbosity.policy.hcl) policy.
