# Ensure That the 'Log_min_duration_statement' Database Flag for Cloud SQL PostgreSQL Instance Is Set to '-1' (Disabled)

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Logging |

## Description

This control checks that Cloud SQL for PostgreSQL instances (`google_sql_database_instance` with a `POSTGRES` `database_version`) set the `log_min_duration_statement` database flag to `-1` (disabled), if it is set. Values are compared case-insensitively. If the flag is not set, the instance passes because the engine default is compliant. Read replicas are evaluated too, because database flags are not inherited from the primary. The same check applies to `google_database_migration_service_connection_profile` resources that create a Cloud SQL destination instance through `cloudsql.settings.database_flags`.

When `log_min_duration_statement` is enabled, PostgreSQL logs the full text of every statement that runs longer than the threshold. Those statements can contain sensitive data, such as values in `INSERT` or `UPDATE` statements, which should not be written to logs.

This rule is covered by the [6-2-7-log-min-duration](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/6-2-7-log-min-duration.policy.hcl) policy.
