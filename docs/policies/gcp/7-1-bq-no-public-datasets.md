# Ensure That BigQuery Datasets Are Not Anonymously or Publicly Accessible

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Resources not publicly accessible |

## Description

This control checks that BigQuery datasets are not shared with `allUsers` or `allAuthenticatedUsers`. It inspects the `access` blocks of `google_bigquery_dataset` (`special_group` and `iam_member`), `google_bigquery_dataset_access`, and the dataset IAM resources `google_bigquery_dataset_iam_member`, `_iam_binding`, and `_iam_policy` (with decoded `policy_data`). The `iamMember:allUsers` and `iamMember:allAuthenticatedUsers` forms that the IAM resources accept are also detected. Table-level IAM is outside the scope of this dataset-level control.

Granting a dataset to `allUsers` or `allAuthenticatedUsers` allows anyone on the internet, or any Google account, to read its tables. Datasets often contain sensitive business or personal data, so access should be limited to specific users, groups, or domains. A dataset that omits `access` blocks gets non-public defaults, but the value is unknown during a plan and may be reported as unknown.

This rule is covered by the [7-1-bq-no-public-datasets](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/bigquery/7-1-bq-no-public-datasets.policy.hcl) policy.
