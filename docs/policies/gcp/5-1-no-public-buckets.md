# Ensure That Cloud Storage Bucket Is Not Anonymously or Publicly Accessible

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Storage security |

## Description

This control checks that Cloud Storage buckets and their objects are not granted to `allUsers` or `allAuthenticatedUsers`. It covers bucket IAM (`google_storage_bucket_iam_member`, `_iam_binding`, and `_iam_policy` with decoded `policy_data`), managed folder IAM (`google_storage_managed_folder_iam_*`), and legacy ACLs (`google_storage_bucket_acl` `role_entity`, `predefined_acl`, and `default_acl`; `google_storage_bucket_access_control`; `google_storage_default_object_acl` and `_access_control`; `google_storage_object_acl` and `_access_control`). The predefined ACLs `publicRead`, `publicReadWrite`, and `authenticatedRead` are treated as public.

Granting a bucket or object to `allUsers` makes its contents readable by anyone on the internet, and `allAuthenticatedUsers` extends access to every Google account. Public grants are a common cause of data exposure. IAM conditions cannot be applied to these principals, so conditional grants are still reported. An enforced public access prevention setting is not treated as a mitigation, because an inherited organization-level setting is not visible in the plan and the grant itself remains a configuration error.

This rule is covered by the [5-1-no-public-buckets](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/storage/5-1-no-public-buckets.policy.hcl) policy.
