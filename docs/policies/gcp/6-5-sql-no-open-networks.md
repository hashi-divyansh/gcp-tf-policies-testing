# Ensure That Cloud SQL Database Instances Do Not Implicitly Whitelist All Public IP Addresses

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Network security |

## Description

This control checks that no `settings.ip_configuration.authorized_networks` entry of a `google_sql_database_instance` allows any address. Any value with a `/0` prefix length, such as `0.0.0.0/0` or `::/0`, fails. Ranges that split the address space into several entries (for example `0.0.0.0/1` and `128.0.0.0/1`) are not detected.

An authorized network of `0.0.0.0/0` lets any host on the internet reach the instance's public IP address, leaving only database authentication between attackers and the data. Restricting authorized networks to known addresses reduces the attack surface.

This rule is covered by the [6-5-sql-no-open-networks](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/6-5-sql-no-open-networks.policy.hcl) policy.
