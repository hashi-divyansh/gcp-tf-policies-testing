# Ensure 'cross db ownership chaining' Database Flag for Cloud SQL SQL Server Instance Is Set to 'off'

| Provider | Category | CIS Control (GCP v5.0.0) |
| -------- | -------- | ------------------------ |
| Google Cloud Platform | Database security | 6.3.2 |

## Description

This control checks that Cloud SQL for SQL Server instances (`google_sql_database_instance` with a `SQLSERVER` `database_version`) set the `cross db ownership chaining` database flag to `off`, if it is set. Values are compared case-insensitively. If the flag is not set, the instance passes because the engine default is compliant. Read replicas are evaluated too, because database flags are not inherited from the primary. Database Migration Service connection profiles are not checked because their Cloud SQL destination supports only MySQL and PostgreSQL versions.

Cross-database ownership chaining lets permissions on objects in one database extend to objects in other databases with the same owner. This can let users reach data in databases they were never granted access to.

This rule is covered by the [cloudsql-sqlserver-cross-db-chaining-disabled](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/cloudsql-sqlserver-cross-db-chaining-disabled.policy.hcl) policy.
