# Ensure That the 'Log_connections' Database Flag for Cloud SQL PostgreSQL Instance Is Set to 'On'

| Provider | Category |
| -------- | -------- |
| Google Cloud Platform | Logging |

## Description

This control checks that Cloud SQL for PostgreSQL instances (`google_sql_database_instance` with a `POSTGRES` `database_version`) set the `log_connections` database flag to `on`. Values are compared case-insensitively. If the flag is not set, the instance fails because the engine default is non-compliant. Read replicas are evaluated too, because database flags are not inherited from the primary. The same check applies to `google_database_migration_service_connection_profile` resources that create a Cloud SQL destination instance through `cloudsql.settings.database_flags`.

Logging every connection attempt and successful authentication gives an audit trail for detecting unauthorized access and investigating incidents. PostgreSQL does not log connections by default.

This rule is covered by the [6-2-2-log-connections](https://github.com/hashicorp/prewritten-terraform-policy-library/blob/main/policies/gcp/sql/6-2-2-log-connections.policy.hcl) policy.
